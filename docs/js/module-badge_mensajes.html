Module: badge_mensajes

Módulo de notificaciones de mensajes no leídos. Actualiza automáticamente el badge del icono de mensajes consultando el servidor cada 5 segundos.

Methods

(async, inner) actualizarBadgeMensajes() → {void}

Consulta el número de mensajes no leídos del usuario actual y actualiza todos los badges con id="badge-mensajes" en el DOM. Si el contador es 0, oculta el badge; si es mayor, lo muestra.
