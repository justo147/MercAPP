Clase User

Gestiona todas las operaciones relacionadas con los usuarios:

  • Registro
  • Autenticación
  • Verificación de email
  • Recuperación de contraseña
  • Edición de perfil
  • Administración (roles y estados)
  • Estadísticas del usuario
